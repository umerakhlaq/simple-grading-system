# 🎓 Ultra Stylish Grading System

A modern and animated web-based grading system using HTML, CSS, and JavaScript. Enter your marks and instantly see your grade with a beautiful, responsive glassmorphism UI.

## ✨ Features

- 🔮 **Glassmorphism Design** – Smooth, blurred, and modern card layout
- 🎯 **Instant Grade Check** – Grade calculated based on entered marks
- 💡 **Animated Feedback** – Grade result with glowing effect
- 📱 **Responsive Layout** – Works seamlessly on all devices
- ⚡ **Zero Dependencies** – No libraries or frameworks needed

## 📊 Grading Criteria

| Marks         | Grade |  
|---------------|--------|
| 90 and above  | A      |
| 80 - 89       | B      |
| 70 - 79       | C      |
| 60 - 69       | D      |
| Below 60      | Fail   |
